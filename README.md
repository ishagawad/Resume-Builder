# Resume Builder

A modern, interactive Resume Builder web application built with **React**, **Vite**, **Tailwind CSS**, and **Bootstrap**.

## Features

- Dynamic resume templates
- Live text editing and preview
- PDF export support with `jspdf` and `html2canvas`
- Responsive design

## Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS & React Bootstrap
- **Icons**: Lucide React
- **Exporting**: jsPDF & html2canvas

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```
